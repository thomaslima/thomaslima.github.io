Steps to create this website inspired from:
- https://gohugo.io/getting-started/quick-start/

Test locally:
make sure the gitmodules are downloaded properly:
- `git submodule update --init --recursive`
Make sure hugo is installed
- `brew install hugo`
Run hugo locally
- `hugo server`
